# Code of conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise code and ideas rather than people, and keep discussions about the work. Harassment of any kind is not accepted, in issues, pull requests or reviews.

To report a problem, contact a maintainer privately through GitHub ([@omarbounawarapy](https://github.com/omarbounawarapy)). Reports are kept confidential. Maintainers may remove comments, lock threads or block accounts that break these rules.
