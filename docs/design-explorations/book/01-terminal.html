HOW THIS MAPS TO THE REAL PROJECT

  • Same pages, same data. Orders to check, WhatsApp messages, Add an order, Money saved, Activity log and the AI-health pages each become one or more mnemonic panels with their real copy.
  • What changed after the client test. Plain-word tiers (RISKY, UNSURE, SAFE) with French and Arabic glosses; every key named in words; a compact desktop list; an alert strip with the counts on top; one-tap send; a pre-filled reply; colour-coded address check; a readable audit trail; French and Arabic phone screens; bigger phone type.
  • Codebase impact. A panel grid with a global command parser (ORD, MSG, ADD, RES…), keyboard-first actions (1, 2, 3, F-keys), monospaced tables, and real i18n with right-to-left layout. The API is unchanged.
  • Honest cost. It still rewards daily users more than first-timers, and amber on black is tiring in bright rooms. The French and Arabic screens cover the list only; the other screens need full translation before this could ship.
