# Persona test kit

Seven role-played clients (see the other files). To test a design: save screenshots to `_review/<design>/` named `desktop-d1..d7.png`, `phone-m1..m6.png`, `brand-sheet.png`, then spawn one small-model agent per persona with a prompt that gives the persona file path, the design folder, and a one-paragraph description of the design style. Agents must only read images and must not edit files. Results are simulated hypotheses, not market evidence.

Version 2 of Terminal Desk has extra phone screens phone-m7 (French) and phone-m8 (Arabic, right to left). Personas who read French or Arabic should view them.
