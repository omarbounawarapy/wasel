Wasel: brand directions, round 2

Redone from research. The first six directions broke rules I then read in the skill's own refuse list (eyebrow labels, hero-number templates, glass and gradient tiles, Inter, instrument and newspaper costumes). This round starts from what real brand schools teach, then from the seller's own Tunisian world, and lets the world lend only type, palette, density and one signature move.

ASSIGNED BY THE ROLL

Mosaïque

World: Zellige and Maghrebi tile geometry

Design idea, written before drawing

A zellige panel is made of identical glazed units set to a rule. Wasel's score is made of reasons that each move it by a few points. So the reasons become tiles: one small glazed square is about 3 points, clay raises the risk, turquoise lowers it. In the list the tiles form a short strip you read like a bar; in the detail the same tiles stack into a panel, and the 'if they give a full address' panel sits under it at the same scale, so v1 to v2 is seen as clay turning to turquoise. The logo comes from the same geometry: two squares (two parcels, seller and customer) turn 45 degrees into the khatem star. It is the one decorative form; everything else is a standard, quiet product screen.

What the world lends (Operate rules)

type: geometric grotesk + Kufi · palette: cobalt rail, glaze colours as state · density: compact table · move: reasons as glazed tiles

Honest risk

Maghrebi geometry is the tourist-poster rut. The defence is restraint: one tile unit, no tessellated backgrounds, no arabesque borders. The star must read as two squares first, not as a generic Islamic star.

IMPECCABLE'S PICK

Bordereau

World: Courier waybills and rubber stamps

Design idea, written before drawing

Sellers know the paper this product replaces: the courier's duplicate waybill, filled in by hand, stamped when something is decided. Wasel already makes one decision per order, so that decision gets one authored verdict stamp on the order (CONFIRMER L'ADRESSE), set slightly off-square like a real stamp. The score history uses the copies: the white original is v1, the pink copy is v2. Order numbers and amounts are set in a typewriter face because they are typed data; everything else is a clean sans. The logo is a postmark roundel with the door in it, and the wavy cancellation lines trail off it.

What the world lends (Operate rules)

type: narrow grotesk + typewriter for data · palette: carbon blue, stamp red, copy tints · density: form-dense but standard table · move: one verdict stamp, versions as carbon copies

Honest risk

Stamps and form textures are an easy costume. The rule is one stamp per order and no ruled-paper table. The roundel logo must not look like a post office.

Logo derived from the world

CHALLENGER · COMPETITIVE

Ligne

World: Metropolitan rail diagram (Tunis light rail)

Design idea, written before drawing

An order is already a journey: message, scored, question asked, reply, rescored, shipped, the door. Draw it as a transit line with stations. The line is red while the risk is high; when the customer replies with a full address it turns green from the station 'Rescored', and a dashed branch shows 'Refused' as the diversion that costs money. In the list each order carries a seven-dot mini journey. The logo is the same grammar: a line leaving a station and ending at a door.

What the world lends (Operate rules)

type: wayfinding humanist · palette: midnight shell, line colours as risk · density: signage-clear · move: order journey as a line that changes colour

Honest risk

The line must carry real states only. Verdict: competitive. It beats the assignment on product clarity (the journey is a real need) but identification is narrower than the tile or stamp for sellers outside Tunis.

CHALLENGER · COMPETITIVE

Module

World: Wim Crouwel gridded letterforms

Design idea, written before drawing

Every number in Wasel is a measurement. Crouwel built letterforms from visible cells, so the score is drawn as grid digits (87 above), the page keeps a faint construction grid you can switch on, and the logo is the door built from the same 6 by 6 cells. Colour is nearly absent: ink and white, with one signal plane that appears only when risk is high.

What the world lends (Operate rules)

type: neutral grotesk + grid-built numerals · palette: ink, white, one signal plane · density: measured · move: score numerals built from cells

Honest risk

Crouwel is Dutch and reads cold; identification with Tunisian sellers is weak. Verdict: competitive on clarity only. The discipline kept is the visible baseline grid and the measured density.

Declined challengers and what the build kept from each

  • Dark-first developer consoleDeclined: the user is a seller, not a developer.

    Kept: the destructive action is isolated. Cancel order now sits apart from the other buttons in every direction.

  • Botanical folio platesDeclined: warm cream is already spent and the subject is wrong.

    Kept: same-scale plates. The 'now' and 'if they reply' panels are drawn at identical scale so the change reads at a glance.

  • Variable-font specimenDeclined: audience gets nothing from a type playground.

    Kept: weight as meaning. The top reason is set heavier than the rest instead of using a coloured pill.

  • Convention circle catalogueDeclined: wrong audience and density.

    Kept: hand marks for state. Orders the seller has already handled can be marked seen, not just coloured.

The standing exit

If you prefer the category standard played straight (a clean light dashboard in the manner of Stripe or Linear, no world at all), say so and that becomes the commitment at full fidelity. I have not recommended it.
